# Validação da proteção da branch principal

Este arquivo existe apenas para validar o fluxo protegido da `main`.

Critérios esperados antes do merge:

- Pull request obrigatório.
- Conversas resolvidas.
- `CI summary` aprovado.
- `Security summary` aprovado.
- Branch atualizada com a `main`.
- Force-push bloqueado.

Após a validação, este arquivo pode ser mantido como evidência documental do processo de proteção do repositório.
